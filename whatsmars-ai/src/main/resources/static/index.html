whatsmars-ai
基于 TokenStream + SSE 实现流式输出，调用 GET /ai/stream/chat?message=...，实时显示 AI 逐字回复。
AI 根据问题自动调用工具，调用 GET /ai/tool/chat?message=...，流式输出。
可用工具：实时时间查询、日期差计算、HTTP 请求（GET/POST）、网络搜索（Tavily）、系统环境信息。
基于自定义 RetrievalAugmentor 的检索增强生成（RAG），调用 GET /ai/retrieval/chat，流式实时输出。
使用 ExpandingQueryTransformer 将查询扩展为 3 条变体，分别检索后合并去重，召回率更高。
知识库包含 Spring Boot 核心知识和 Java 并发编程文档。
基于 @MemoryId 的多轮对话记忆，流式输出，调用 GET /ai/memory/chat?sessionId=...&message=...。
相同 sessionId 的对话会保留上下文，不同 sessionId 互相隔离。
AI 通过 MCP 协议（Streamable HTTP）连接远程 MCP Server，调用 GET /ai/mcp/chat?message=...，流式输出。
可用工具：天气查询（Open-Meteo）、地图服务（百度地图 URI API）。
